# CReAMer Inspection App - Android Installation

## File
The application binary is: `Inspection_App_v1.0.apk`

## How to Install via Cable
1. Connect your Android phone to this computer via USB.
2. On your phone, change the USB mode to "File Transfer" or "MTP".
3. Copy the `Inspection_App_v1.0.apk` file from this folder to your phone's storage (e.g., to the "Downloads" folder).
4. On your phone, open a File Manager app and locate the APK.
5. Tap the APK to install. 
   - *Note: If prompted, allow "Install from Unknown Sources".*
6. Launch the "Inspection" app from your app drawer.

## Key Features in this Build
- **Barcode Validation**: Scans barcodes and validates against the CReAMer database.
- **Smart Camera Discovery**: Includes retry logic if hardware is slow to initialize.
- **Vehicle Photos**: Support for Ghost overlays to align vehicle angles.
- **Odometer Scanning**: Automated OCR for odometer readings.
